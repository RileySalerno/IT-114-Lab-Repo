# IT-114-Lab-Repo
All of the Labs from 01- 07 for the class IT 114, done by Riley Salerno, Testing for commits


Compile instructions:
1. download the RPSServer, RPS_GUI, RPSLeaderboard, and LeaderboardGUI, along with the 3 .png files
2. Open these files in vscode and put the png files into a folder called "Icons" in the hierarchy
3. First compile the RPSserver file by pressing the run button
4. then open as many RPS_GUI clients as you want
5. if you want to see the leaderboard of the game then open the leaderboardGUI file to have it displayed
6. now everything should be properly set up once all of these are open
